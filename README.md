# Tsundere Shell

A playful little command shell written in C, designed to act like a tsundere personality: it runs your commands, scolds you when you make mistakes, and sometimes punishes you with a bit of chaos if you type something wrong.

Built for fun, experimentation, and a little bit of harmless mischief, Tsundere Shell is a small project with a lot of personality.

## Features

- Runs commands in a shell-like environment
- Simple C-based implementation
- A teasing, dramatic command-line personality
- A playful warning system for invalid or reckless input
- A reminder that command execution can have consequences

## Why this project exists

This shell was created as a lighthearted project with a strong character theme. It is meant to be fun, a little dramatic, and intentionally memorable. It is not meant to be a full production shell, but it is a great starting point for learning process management, command parsing, and shell behavior in C.
